# hangul2kata

한국어 문장을 일본어 가타카나 발음으로 표기하는 브라우저 도구입니다. 번역기가 아니며, 한글 이외의 문자는 입력 원문을 보존합니다.

## 목표
- 가사카드 제작을 위한 한국어 → 가타카나 발음 표기
- 브라우저 내 로컬 처리. 입력 텍스트를 외부로 전송하지 않음
- 표준 발음 처리와 특정 참조 사이트 출력 재현은 별도 평가
- 사용자 사전은 브라우저 localStorage에 저장하고 JSON으로 내보내기/가져오기

## 개발 상태
현재 저장소는 v1.2 기반의 초기 구현 단계입니다. 변환 규칙은 검증 가능한 작은 단위로 확장하며, 아직 참조 사이트와의 완전한 출력 일치를 보장하지 않습니다.

## 기본 설정
- `ng_style: "na"`
- `final_style: "small"`
- `boundary_mode: "independent"`

## 실행
정적 웹 앱이므로 `web/index.html`을 브라우저에서 열거나 GitHub Pages로 배포할 수 있습니다.

테스트:
```bash
npm test
```

## 구조
- `src/`: 브라우저/Node 공용 순수 JavaScript 변환 코어
- `web/`: UI
- `tests/`: Node 내장 테스트
- `.github/workflows/deploy.yml`: GitHub Pages 배포

## 개인정보 및 데이터 보호
- 입력 문장은 서버로 전송하지 않습니다.
- 가사 원문, 최종 가사카드, 개인 정답 데이터는 공개 저장소에 올리지 마세요.
- 사용자 사전 데이터는 브라우저 localStorage에만 저장됩니다.
- GitHub Pages 방문자의 접속 IP 등은 GitHub의 서비스 운영 과정에서 처리될 수 있습니다.

## 평가 기준
다음 세 지표를 혼합하지 않고 따로 관리합니다.
1. 표준 발음 예시 통과율
2. 참조 사이트 출력 재현율
3. 최종 PDF/XLSX 가사카드 재현율

참조 사이트 출력은 표준 발음의 정답으로 간주하지 않습니다.
