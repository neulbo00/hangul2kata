사용자 사전

선택 기능입니다. 인명·그룹명·특수 표기처럼 기본 변환을 바꾸고 싶을 때만 사용하세요. 공백으로 구분된 어절 전체에 적용되며, 이 브라우저에만 저장됩니다. 사용자 사전은 기본 아티스트 사전보다 우선 적용됩니다.

아티스트 사전은 그룹별 JSON 파일입니다. 그룹 버튼을 누르면 파일을 불러와 등록된 그룹명과 멤버 표기를 확인할 수 있습니다. 변환에 사용할지는 ‘사전 적용’ 체크로 켜고 끌 수 있습니다. 개인 사용자 사전도 같은 설정을 따릅니다. 예문 입력은 별도 버튼으로 실행합니다.

아티스트 사전 예시

그룹을 선택하면 해당 그룹의 JSON 파일을 불러와 멤버 표기를 확인합니다. 실제 변환 적용은 ‘사전 적용’ 체크로 제어합니다.
